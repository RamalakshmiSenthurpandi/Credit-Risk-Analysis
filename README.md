# Credit Risk Analysis using Machine Learning

## Overview

This project predicts whether a customer is likely to become a good debt or bad debt using machine learning techniques. It demonstrates an end-to-end machine learning pipeline, from data preprocessing to model deployment using Streamlit.

## Business Problem

Financial institutions face significant losses due to customer defaults. This project helps identify risky customers in advance so that informed lending decisions can be made.

## Features

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning Model Training
- Model Evaluation
- Streamlit Web Application
- Customer-level Prediction

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- CatBoost
- Streamlit
- Joblib

## Workflow

1. Data Collection
2. Data Preprocessing
3. Feature Engineering
4. Model Training
5. Model Evaluation
6. Streamlit Deployment
