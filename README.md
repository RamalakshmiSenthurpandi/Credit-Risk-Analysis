# Credit Risk Analysis

## Project Overview

Credit Risk Analysis is a Machine Learning project developed to predict whether a customer is likely to be a Good Credit Risk or a Bad Credit Risk based on historical customer and financial information. The project helps financial institutions make informed lending decisions by identifying high-risk customers before approving loans.

**Note:** The original dataset used in this project is confidential and is not included in this repository. A sample dataset can be used for demonstration purposes.

---

## Objectives

* Predict customer credit risk.
* Support informed loan approval decisions.
* Reduce financial losses due to loan defaults.
* Demonstrate an end-to-end machine learning workflow for credit risk assessment.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Credit-Risk-Analysis.git
```

Navigate to the project directory:

```bash
cd Credit-Risk-Analysis
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
